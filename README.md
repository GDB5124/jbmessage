# JBMsgSender

JBEdu Messenger+와 함께 사용하는 Windows용 쪽지 발송 도우미입니다. 현재 공개 버전은 **v1.0.12**입니다.

## 다운로드

[최신 정식 릴리스](https://github.com/GDB5124/jbmessage/releases/latest)

- **처음 사용:** 릴리스의 `JBMsgSender_v1.0.12.zip`을 내려받아 압축을 모두 풀고 `JBMsgSender.exe`를 실행하세요. EXE·엑셀 양식·사용안내·안내 이미지 6종이 포함되어 있습니다. 개발용 소스와 테스트 자료는 배포 ZIP에 포함하지 않습니다.
- **단독 실행 / 자동 업데이트:** `JBMsgSender.exe`
- **양식만 다운로드:** `JBMsgSender_template.xlsx`
- Python 설치는 필요하지 않습니다. Windows에 JBEdu Messenger+가 설치되어 있고 로그인되어 있어야 합니다.

## 자동 업데이트

자동 업데이트 기능이 포함된 배포본은 실행할 때 GitHub의 최신 정식 릴리스를 확인합니다. 더 높은 버전의 `JBMsgSender.exe`가 있으면 크기와 SHA-256을 검증한 뒤 로컬 캐시에서 실행합니다. 인터넷 연결이나 업데이트에 문제가 있으면 기존 버전으로 실행합니다. 이미 최신 버전이면 그대로 실행합니다.

제작자는 버전을 올려 빌드한 EXE를 정식 릴리스에 `JBMsgSender.exe`라는 이름으로 첨부해야 합니다. 저장소에 파일을 올리거나 ZIP만 첨부하는 것으로는 자동 업데이트되지 않습니다.

## 기능

- 엑셀 검증·미리보기, 테스트 발송 1건, 결과 별도 저장과 오류 로그
- 개인별 발송 및 한 쪽지창에 공통 수신자 자동 추가
- G열 파일·폴더 및 여러 파일 순차 첨부, 공통 첨부 폴더
- 선택 행 첨부 편집으로 G열 경로 저장과 원본 백업
- 전송 직전 확인 선택(기본 체크, 해제하면 확인창 없이 전송)
- 엑셀 H~J열 개인별 예약과 GUI 공통 기본 예약 설정
- 선택된 탭 확대와 JB 배지형 아이콘

공통 수신자는 이름·소속을 하나의 대상으로 확정할 수 있으면 자동 추가하며, 중복·불일치·판독 실패 때는 사용자 확인을 요청합니다. 공통 쪽지는 본문·첨부·예약 설정이 같아야 합니다.

## 이용 안내

업무 목적의 특정 수신자 안내에 사용하는 비공식 보조 도구입니다. 먼저 엑셀 미리보기·첨부 진단·작성만 기능으로 확인하고 본인 대상 1건 시험을 진행하세요.

자동 처리 중에는 마우스·키보드 조작과 창 전환, 메신저 이동·최소화를 멈추고 완료 또는 중단 안내까지 기다리세요. 현재 입력 잠금이나 자동 일시정지 기능은 없습니다.

예약은 미래 시각과 5분 단위를 사용합니다. 예약 등록 요청 기록만으로 실제 등록·수신이 확인되는 것은 아니므로 메신저에서 결과를 확인하세요. 달력 선택·시분 드롭다운 개선안은 현재 포함되어 있지 않습니다. 동봉 안내 이미지는 1.0.11 화면 기준이며 예약 검증 범위 안내를 포함합니다.

HWP/XLS/DOC/PPT는 사전 차단하며 HWPX/XLSX/DOCX/PPTX로 변환 후 첨부하세요. 불필요한 개인정보 파일은 보내지 말고, 불가피하면 파일 자체에 암호를 설정하세요. 다른 PC 환경과 메신저의 첨부 개수·용량 제한은 사용 환경에서 확인해야 합니다.
