# JBMsgSender

JBEdu Messenger+ 쪽지 발송 도우미입니다. Windows에서 로그인된 메신저와 함께 사용합니다.

## 다운로드

[최신 릴리스 다운로드](https://github.com/GDB5124/jbmessage/releases/latest)

- 실행: 릴리스의 `JBMsgSender.exe`를 내려받으세요. Python 설치 없이 실행합니다.
- 처음 사용: 배포 ZIP에는 엑셀 양식, 사용설명서, 안내 이미지, 소스가 포함되어 있습니다. 압축을 모두 풀어 사용하세요.
- 자동 업데이트: 실행할 때 최신 정식 릴리스를 확인하고 SHA-256을 검증한 새 EXE를 로컬 캐시에서 실행합니다. 실패하면 기존 버전으로 실행합니다.

## 기능

- 엑셀 검증 및 미리보기, 테스트 발송 1건
- 개별 발송 및 공통 쪽지 수신자 추가
- 파일·폴더 선택으로 G열 첨부 경로 저장 및 원본 백업
- 여러 파일 순차 첨부, 전송 직전 사용자 확인
- 결과 별도 저장 및 오류 로그

공통 쪽지의 수신자 검색 결과는 이름·소속을 사람이 확인하여 선택합니다. 다른 PC 호환성과 메신저 첨부 한계는 별도 확인이 필요합니다.

## 이용 안내

업무 목적의 특정 수신자 안내에 사용하세요. 메신저 이용 규정을 확인하고, 먼저 미리보기와 첨부 진단을 실행하세요. 실제 전송은 화면에서 수신자·본문·첨부를 확인한 후에만 진행합니다.

사용자가 제공한 2026-10-01 첨부 정책에 따라 HWP/XLS/DOC/PPT는 사전 차단하며 HWPX/XLSX/DOCX/PPTX 변환을 안내합니다. 불필요한 개인정보 파일은 전송하지 말고, 불가피한 경우 암호를 설정하세요.
